Arduino Sensor Practice Codes

Files included:
1. LED Blinking
2. IR Sensor - Object Detection
3. LDR - Analog Light Reading
4. DHT11 - Temperature and Humidity
5. Ultrasonic - Distance Measurement
6. IR Sensor with LED
7. LDR with LED
8. Ultrasonic with LED

Libraries:
- DHT11 code requires the DHT sensor library by Adafruit.

Note:
- Pin numbers are simple example pins. Change them according to your board and wiring.
- For ESP32-S3, A0 and GPIO numbers can differ from Arduino Uno. Use the pins available on your specific board.
- HC-SR04 Echo may output 5V; use a voltage divider before connecting Echo to a 3.3V ESP32 GPIO.
